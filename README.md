# Fed Prediction Markets Dashboard

This project was unpacked from the bundled archive and implemented as a static dashboard.

## Quick start

Open `index.html` in a browser, or serve the folder locally:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Dashboard features

- Executive KPI summary cards
- Signal strength chart
- Risk regime distribution
- Policy path / horizon diagnostics
- Evidence table for model results
